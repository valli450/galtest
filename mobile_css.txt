МОБИЛЬНАЯ ВЕРСИЯ (ширина < 600px)
====================================

1. КАРТИНА (3D сцена) — ширина 90%
   Три штуки через `clamp()`:
   PAINT_SIZE = 1.7 (уже есть в JS)

2. БЛОК СПРАВА (info-right) — информация о картине
   - Сверху экрана
   - Текст по центру
   - Название, описание, музей

3. БЛОК СЛЕВА (letter-left) — цитата из письма
   - Снизу экрана
   - Текст по центру
   - Цитата курсивом, ссылка на письмо

--------------------------------------------------------------
ПРЕДЛАГАЕМЫЙ CSS (вставить в @media (max-width:600px)):
--------------------------------------------------------------

/* ---- картина на 90% ширины ---- */
/* PAINT_SIZE = 1.7 уже задан в JS, менять не нужно */

/* ---- блок информации (сверху) ---- */
.info-right{
  right:5%; left:5%;          /* отступы по бокам */
  top:20px;                    /* отступ сверху */
  bottom:auto;                 /* не привязан к низу */
  max-width:none;              /* без ограничения ширины */
  text-align:center;           /* текст по центру */
  transform:none !important;   /* убираем translateY(-50%) */
}
.info-right .eyebrow{
  font-size:9px;               /* "Зал · № 01" */
  letter-spacing:.3em;
}
.info-right .title{
  font-size:18px;              /* название картины */
}
.info-right .desc{
  font-size:11px;              /* описание */
  line-height:1.5;
}

/* ---- блок цитаты (снизу) ---- */
.letter-left{
  left:5%; right:5%;           /* отступы по бокам */
  top:auto;                    /* не привязан к верху */
  bottom:20px;                 /* отступ снизу */
  max-width:none;
  text-align:center;
  transform:none !important;   /* убираем translateY(-50%) */
}
.letter-left .quote{
  font-size:11px;              /* цитата */
  line-height:1.5;
}
.letter-left .ref{
  font-size:9px;               /* ссылка на письмо */
}

/* ---- картина в центре, 90% ---- */
/* PAINT_SIZE = 1.7 уже в JS, R_ART = 8, камера на расстоянии */
